CMS berbasis GitHub adalah pendekatan pengelolaan konten yang menyimpan data website langsung di repository. Konten dapat berupa Markdown, JSON, gambar, dan aset statis lain. Setiap perubahan akan tercatat sebagai commit, sehingga riwayat edit lebih mudah dilacak.

Pendekatan ini cocok untuk website company profile, blog, dokumentasi, landing page, dan website bisnis yang tidak membutuhkan fitur database kompleks. Hasil akhirnya berupa website statis yang ringan, cepat, dan mudah di-hosting di GitHub Pages atau layanan hosting statis lain.

## Keunggulan CMS berbasis GitHub

Keunggulan utamanya adalah sederhana dan transparan. Konten tidak tersimpan di database tertutup, melainkan sebagai file yang bisa dibaca dan dipindahkan kapan saja. Bagi pemilik website, ini memberikan kontrol lebih besar terhadap aset digitalnya.

Website statis juga relatif cepat karena halaman sudah dibangun sebelumnya. Pengunjung tidak perlu menunggu server memproses database setiap kali halaman dibuka.

## Cocok untuk company profile dan blog

Untuk company profile, section seperti hero, layanan, profil, keunggulan, kontak, dan CTA dapat disimpan dalam file JSON. Admin dapat mengedit section tersebut melalui panel, lalu GitHub Actions membangun ulang website secara otomatis.

Untuk blog, artikel dapat ditulis dalam Markdown. Penulis cukup mengisi judul, slug, kategori, tanggal, excerpt, featured image, dan konten utama. Setelah disimpan, file masuk ke repository dan website akan diperbarui.

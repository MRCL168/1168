Token disimpan di browser Anda dan dipakai hanya untuk akses repository.
Cara membuat token →
  1. Buka GitHub → Settings → Developer settings.
  2. Pilih Personal access tokens → Fine-grained tokens.
  3. Beri akses ke repository CMS Anda.
  4. Set permission Contents ke Read and write.
